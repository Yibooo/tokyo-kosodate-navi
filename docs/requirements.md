### Phase 0：基盤構築 ✅ 完了

**[P0-1] 制度データパイプライン**
- スクレイピング対象：国（こども家庭庁・厚生労働省等）/ 東京都（福祉局）/ 23区（各公式サイト）
- Claude API がHTMLから制度情報を抽出し、構造化JSONとして保存
- 抽出項目：制度名 / 対象条件（年齢・所得・子の順番）/ 給付額 / 申請方法 / リンク / カテゴリ / 有効期限
- 管理者がAPIエンドポイント叩きで手動実行（Cronは将来対応）
- 実行後、管理者へメール通知（Resend）

**[P0-2] 管理者レビュー画面** `/admin/review`
- ドラフト制度の一覧表示（承認待ち / 承認済み / 却下済みのタブ）
- 管理者が「承認 / 却下」の2アクションで確定
- 承認分のみ本番DBへ反映される仕組み

**[P0-3] 制度マスタDB設計**（Supabase PostgreSQL）

```sql
-- 制度テーブル
policies (
  id UUID PRIMARY KEY,
  layer TEXT,          -- 'national' | 'tokyo' | 'ward'
  ward TEXT,           -- 区名（国・都は null）
  name TEXT,
  summary TEXT,
  category TEXT,       -- 8カテゴリ（後述）
  amount_monthly INT,  -- 月額（円）
  amount_lump INT,     -- 一時金（円）
  amount_note TEXT,    -- 補足説明
  apply_url TEXT,
  source_url TEXT,
  valid_from DATE,
  valid_to DATE,
  status TEXT          -- 'draft' | 'approved' | 'rejected'
)

-- 条件テーブル
policy_conditions (
  policy_id UUID REFERENCES policies(id),
  income_max INT,      -- 所得制限（万円）
  child_age_min INT,   -- 対象年齢 最小（月）
  child_age_max INT,   -- 対象年齢 最大（月）
  birth_order_max INT  -- 第何子まで
)

-- スクレイピングログ
scrape_logs (
  id UUID PRIMARY KEY,
  target_name TEXT,
  target_url TEXT,
  status TEXT,
  policies_found INT,
  policies_skipped INT,
  error_message TEXT,
  started_at TIMESTAMPTZ,
  finished_at TIMESTAMPTZ
)
```

-- ① 施設数・定員
CREATE TABLE childcare_facilities (
  ward         VARCHAR(20) NOT NULL,

  category     VARCHAR(50) NOT NULL,  -- '認可保育所' | '認定こども園' | '小規模等'

CREATE TABLE waiting_children (
  ward                 VARCHAR(20) NOT NULL,

  waiting_count        SMALLINT    NOT NULL,
  hidden_waiting_count SMALLINT,
  PRIMARY KEY (ward, fiscal_year, age_years)
);

-- ③ 出生数トレンド
CREATE TABLE birth_trends (
  ward         VARCHAR(20) NOT NULL,
  fiscal_year  SMALLINT    NOT NULL,
  birth_count  INT         NOT NULL,
  PRIMARY KEY (ward, fiscal_year)
);

**[B4-2] 難易度スコア算出ロジック**

```typescript
// 需給ギャップ率 = 待機児童数合計 / 認可定員合計 × 100
type DifficultyLevel = 'high' | 'mid' | 'low'

function calcDifficulty(waitingTotal: number, capacityTotal: number): DifficultyLevel {
  const rate = (waitingTotal / capacityTotal) * 100
  if (rate >= 3) return 'high'   // 🔴
  if (rate >= 1) return 'mid'    // 🟡
  return 'low'                   // 🟢
}
```

**[B4-3] 自動コメントテンプレート（ロジックベース）**

| 条件 | コメントパターン |
|------|----------------|
| 待機児童 減少 ＋ 定員 増加 | 「認可定員の拡充が進んでおり、入園難易度は改善傾向にあります」 |
| 待機児童 増加 ＋ 出生数 増加 | 「転入等による出生数増加に施設整備が追いついておらず、競争率が高まっています」 |
| 待機児童 ≒ 0 継続 | 「直近○年間、待機児童ゼロを維持しています。比較的入園しやすいエリアです」 |
| 待機児童 増加 ＋ 出生数 横ばい | 「定員不足が顕在化しています。早めの申し込み・複数園の検討を推奨します」 |

     │                                │
     ▼                                ▼
POST /api/scrape              GET / (入力フォーム)

     ▼                                ▼
Claude API                    ユーザー条件入力
（HTML解析・構造化）                    │
     │                                ▼
     ▼                        GET /results
 scrape_logs                  （ルールベースマッチング）
     │                                │
     ▼                                ▼
policies テーブル             policies テーブル

     │
     ▼
管理者レビュー (/admin/review)
